# 내장 적대적 검증

현재 자료가 허용하는 가장 강한 주장을 검토한다. 대상을 약화해 반박하거나 부족한 전제를 대신 만들어 완성하지 않는다. 검증의 강도는 결함 수나 공격적인 말투가 아니라 근거와 파급 효과의 정확성으로 판단한다.

## 초안 전 증거 검토

질문 지도·출처·주장·열린 리드를 확인한다. 현재 판단을 뒤집을 자료, 누락된 대상이나 조건, 같은 원천의 반복, 기초 자료와 후속 검증의 부재를 찾는다. 중요 공백은 다음 보강 조사에 배정한다. `reviews.jsonl`에 `stage=corpus` 기록을 남긴다. 당시 입력 지문은 이력이며 이후 조사를 금지하는 잠금이 아니다.

## 최종 주장과 계획 검토

핵심 주장마다 다음을 확인한다.

1. **주장·전제:** 무엇을 단정하며 어떤 명시적·숨은 전제가 필요한가.
2. **증거의 효력:** 원문이 정확한 문장을 지지하는가. 관찰·인용·추론·예측을 혼동했는가. 기간·정의·대상이 맞는가.
3. **논리·계산:** 인과 비약·순환·모순·선택 편향이 있는가. 계산은 독립적으로 재검산하고 단위·기간·분모·가정을 확인한다.
4. **강한 반론:** 합리적인 반대 근거와 해당 주장을 방어할 근거를 같은 기준으로 검토했는가.
5. **파급:** 전제가 무너지면 어떤 결론·요건·비용·일정이 영향을 받는가. 치명적인 한 항목을 찾았어도 다른 핵심 주장 검토를 생략하지 않는다.
6. **누락과 실행:** 요청의 중요한 질문을 빠뜨렸는가. 권고는 실행 조건·제약·검증 방법과 연결되는가.

실험 결과를 근거로 한 주장에는 기준선과 평가 계약의 일치, 의도하지 않은 변수 변경, 불리한 결과 누락, 운영 오류와 가설 반증의 혼동을 추가로 점검한다. 로그에 기록된 실제 설정과 결과를 읽고, 화면에 보인 일부 로그만으로 전체 결과를 판정하지 않는다. 판본이 다른 논문의 수치가 섞였거나 동일 문헌의 여러 색인이 독립 근거로 계산되었는지도 확인한다.

본문의 단정에서 장부로, 장부의 핵심 주장에서 본문으로 각각 대조한다. 인용 표식이 없는 새로운 핵심 주장을 찾아 등록·검증하거나 수정한다. 자동 검사는 문장의 의미를 읽지 못하므로 이 점검을 검사 성공으로 대체하지 않는다.

## 결함 처리

확인된 문제를 원인 기준으로 묶고 `판정 → 근거 → 합리적인 방어 논리 검토 → 영향`으로 기록한다. 중요도는 `critical`(핵심 사용 목적 무효), `major`(신뢰성·실행 가능성의 중대한 저하), `minor`(제한적인 문제)다. 증거가 없는 인격·능력·의도 추정은 하지 않는다.

각 결함은 `open`, `resolved`, `dismissed` 상태를 가지며 해결·기각에는 이유와 근거가 필요하다. 반박 의견도 검증 대상이다. 근거 없는 지적은 기각하고, 근거 부족으로 판단할 수 없는 쟁점은 불확실성으로 유지한다. 중대한 결함이 없을 때에는 이를 그대로 기록한다.

중요 수정은 관련 근거·판단·요건을 갱신한 후 재검토한다. 검토한 버전의 입력 지문과 실제 검토 범위를 남긴다. 최종 기록은 최종 보고서와 장부를 포함한 지문에 연결한다. 지문은 변경 식별이며 검토 수행이나 사실의 진실성을 독자적으로 증명하지 않는다.

최종 `verdict`는 `acceptable`, `revise`, `inconclusive`로 남긴다. 핵심 권고를 무효화하는 열린 결함이 있으면 `acceptable`로 처리하지 않는다. 충분히 밝혀진 한계를 가진 조건부 보고서는 전달 가능하지만 미확정 상태와 영향이 본문에 나타나야 한다.

## 역할과 독립성

별도 검토가 허용되고 유용하면 작성 맥락을 전달하지 않은 별도 역할에 원문 요청, 현재 자료, 근거, 범위와 필요한 산출물만 준다. 기대 판정이나 고쳐야 한다는 결론을 미리 주지 않는다. 같은 컨텍스트에서 검토하면 `mode=self`로 기록한다. `mode=independent`는 실제 독립 컨텍스트를 사용했을 때만 기록하며 해당 실행 식별자를 남긴다. 외부 모델 호출이나 하위 작업 생성은 호스트의 권한을 따른다.

연구센터의 내부 검토에 원본 스킬의 호출 조건·페르소나·고정 출력 양식은 적용하지 않는다. 최종 보고서는 사용자의 질문에 답하는 문체로 작성한다.
