# 전달과 재개

## 실행 상태

`run.json`의 `phase`와 `closeout`을 실제 진행에 맞춰 갱신한다. 질문·검색·자료·리드·주장·추적·검토는 하나의 실행 디렉터리에 모은다. 단계 이름이나 완료 플래그만으로 실제 작업 완료를 주장하지 않는다.

재개할 때 다음 순서로 확인한다.

1. `query.md`, `run.json`의 후속 지시·범위·기한, 현재 산출물을 읽는다.
2. 아래 명령으로 누락·변경·열린 질문과 리드를 확인한다.
3. 실패한 검사나 가장 앞선 미완료 작업의 자료를 확인한 후 이어간다.
4. 출처·버전·조건·시점이 유지되는 완료 작업은 재사용한다. 사용자 지시나 자료가 바뀌면 관련 주장·판단·검토만 다시 확인한다.

```bash
python3 /absolute/path/to/my-dear-research-center/scripts/research.py status /absolute/run
```

`status`는 점검 결과를 읽기만 한다. 기록에 없는 과거 수행을 복원하거나 실패 상태를 자동으로 완료로 바꾸지 않는다. 질문 변경은 원문을 덮어쓰기보다 `run.json`의 `amendments`에 시간·내용·영향을 추가한다.

공유 장부는 한 책임자만 쓴다. 위임한 역할은 별도 결과 파일을 반환하고 책임자가 취합한다. 이 패키지의 JSONL 기록은 여러 파일에 걸친 트랜잭션이나 동시 쓰기 잠금을 제공하지 않는다. 파일을 고칠 때에는 작업별 임시 파일에 완성한 뒤 같은 파일시스템에서 교체하고, 중단 후에는 마지막 검증 자료와 대조한다. 손상된 기록을 자동 삭제하거나 조용히 건너뛰어 복구하지 않는다. 공유 데이터베이스·다중 작성이 필요해지면 별도 저장 구조를 설계한다.

## 최종 전달 순서

1. 질문·자료·주장·추적표와 `closeout`을 정리한다. 중요한 열린 질문·리드를 조사하거나 한계와 후속 행동을 기록한다.
2. `report.md`에 사용자에게 전달할 내용을 작성하고 핵심 문장을 `report-map.jsonl`에 연결한다. 실제 출력 형식이 다르면 그 형식의 최종 본문을 `report.md`로 동기화하고 변환본도 확인한다.
3. 초안 전 증거 검토 이력이 있는지 확인하고 최종 보고서와 근거를 읽어 내장 적대적 검토를 수행한다.
4. `fingerprint --stage final`로 현재 입력 지문을 받아 최종 검토 기록에 넣는다. 이때 `reviews.jsonl`만 추가·수정하면 지문이 변하지 않는다. 검토 이후 근거·보고서가 바뀌면 관련 내용을 재검토하고 새 지문으로 기록한다.
5. `validate --final`을 실행해 실제 결과를 확인한다. 구조상 실패는 수정하고, 자료 부족은 숨기지 않고 상태와 문장에 반영한다.

```bash
python3 /absolute/path/to/my-dear-research-center/scripts/research.py fingerprint /absolute/run --stage final
python3 /absolute/path/to/my-dear-research-center/scripts/research.py validate /absolute/run --final
```

검증 결과의 `records_valid`는 기록의 일관성·변경 여부에 대한 판정이다. 원문의 사실성·완전한 읽기·검토 독립성·결론의 정답은 자동으로 보장하지 않는다. `limitations`와 실제 검토 범위를 함께 확인한다.

## 최종 결과의 구성

독자가 먼저 알아야 할 결론을 제시하고 핵심 근거, 중요한 대안과 선택 이유, 적용 조건·미확정 사항, 필요한 다음 행동을 연결한다. 인용은 해당 주장 가까이에 둔다. 원문 링크·문서명·기간·버전·페이지 등 독자가 확인할 정보를 제공한다. 공개 URL이 없는 자료에는 실제 파일명과 위치를 적고 링크를 만들지 않는다.

분량은 요청에 맞춘다. 짧은 답변도 원문 조사와 검증 결과를 압축해 전달한다. 장부의 기술적인 ID를 본문에 노출할 필요는 없다. 중대한 불확실성은 관련 결론에 바로 표시한다.

출력 위치는 현재 작업 공간과 사용자 지시를 따른다. 사용자가 요청하지 않은 PDF·HTML·발표자료·사이트를 자동으로 추가하지 않는다. 외부 게시나 자동 추적을 산출물 작성에 포함시키지 않는다.
